# 🚀 QUICK START GUIDE

## Первый запуск AI Browser Agent

### Шаг 1: Проверка Python

```bash
# Убедитесь что у вас Python 3.9+
python --version
```

Должно быть **Python 3.9.0** или новее.

---

### Шаг 2: Создание виртуального окружения

```powershell
# Windows PowerShell
python -m venv venv
.\venv\Scripts\Activate.ps1

# Если ошибка с политикой выполнения:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Вы должны увидеть `(venv)` перед строкой командной строки.

---

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

Подождите пока установятся все пакеты (~2-3 минуты).

---

### Шаг 4: Установка браузеров Playwright

```bash
python -m playwright install chromium
```

Это загрузит Chromium (~300MB). Подождите завершения.

---

### Шаг 5: Настройка API ключа

1. **Получите API ключ у выбранного провайдера LLM** (например, Groq).

2. **Создайте файл `.env`:**

```bash
# Копируем шаблон
cp .env.example .env

# Откройте .env в текстовом редакторе
notepad .env
```

3. **Добавьте ваш ключ:**

```env
# Пример для Groq (OpenAI-compatible)
API_KEY=gsk_ваш-ключ-здесь
API_BASE_URL=https://api.groq.com/openai/v1
MODEL_NAME=llama-3.3-70b-versatile
```

Сохраните файл.

---

### Шаг 6: Первый запуск! 🎉

```bash
python main.py
```

Вы должны увидеть:
- ✅ Логи инициализации агента
- ✅ Открытие браузера Chromium
- ✅ Выполнение примера задачи
- ✅ Результат в консоли

---

## ❌ Типичные проблемы

### Проблема: `Import "playwright" could not be resolved`

**Решение:**
```bash
# Убедитесь что виртуальное окружение активно
pip install playwright
python -m playwright install chromium
```

### Проблема: `ANTHROPIC_API_KEY не установлен`

**Решение:**
- Проверьте что файл `.env` существует
- Проверьте что ключ начинается с `sk-ant-api03-`
- Перезапустите скрипт

### Проблема: Браузер не открывается

**Решение:**
```bash
# Проверьте что Playwright установлен
python -m playwright install --force chromium
```

### Проблема: `ModuleNotFoundError`

**Решение:**
```bash
# Переустановите зависимости
pip install -r requirements.txt --force-reinstall
```

## 🔧 Настройка под себя

### Изменить режим браузера (headless/headed)

В файле `.env`:

```env
# Показывать браузер (по умолчанию)
HEADLESS=false

# Скрыть браузер (быстрее)
HEADLESS=true
```

### Изменить скорость выполнения

```env
# Замедлить (для отладки)
SLOW_MO=500

# Нормальная скорость
SLOW_MO=100

# Максимальная скорость
SLOW_MO=0
```

### Изменить лимит шагов

```env
MAX_STEPS=50  # По умолчанию
MAX_STEPS=100 # Для сложных задач
MAX_STEPS=20  # Для быстрых тестов
```

## 📦 Chrome Extension (опционально)

### Установка расширения:

1. Откройте Chrome
2. Перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode)
4. Нажмите "Загрузить распакованное" (Load unpacked)
5. Выберите папку `extension/` из проекта
6. Расширение появится в списке!

### Использование:

1. Кликните на иконку расширения в браузере
2. Введите задачу в текстовое поле
3. Нажмите "▶️ Запустить"
4. Наблюдайте за выполнением!

**Примечание:** Расширение работает независимо от Python скрипта.
Для полной интеграции нужен WebSocket сервер (в разработке).
