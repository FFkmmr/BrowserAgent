## 🚀 ПЕРВЫЕ ШАГИ

### ШАГ 1: Установка зависимостей ⏱️ 5 минут

Откройте терминал PowerShell в папке проекта:

```powershell
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать
.\venv\Scripts\Activate.ps1

# 3. Установить пакеты
pip install -r requirements.txt

# 4. Установить браузер Playwright
python -m playwright install chromium
```

---

### ШАГ 2: Настройка API ключа ⏱️ 2 минуты

```powershell
# 1. Скопировать шаблон
Copy-Item .env.example .env

# 2. Открыть .env в редакторе
notepad .env
```

**Добавить ваш Claude API ключ:**
```env
ANTHROPIC_API_KEY=sk-ant-api03-ваш-ключ-здесь
```

💡 Получить ключ: https://console.anthropic.com/

---

### ШАГ 3: Первый запуск! ⏱️ 1 минута

```powershell
python main.py
```

**Вы должны увидеть:**
- ✅ Открытие браузера
- ✅ Выполнение примера задачи
- ✅ Результат в консоли

**Если есть ошибки** → см. `docs/QUICK_START.md`

## 🔧 НАСТРОЙКА ПОД СЕБЯ

### Изменить режим браузера (в `.env`):

```env
# Показывать браузер (для наблюдения)
HEADLESS=false

# Скрыть браузер (быстрее)
HEADLESS=true
```

### Замедлить выполнение (для отладки):

```env
# Нормальная скорость
SLOW_MO=100

# Медленно (для просмотра)
SLOW_MO=500

# Максимальная скорость
SLOW_MO=0
```

### Изменить лимит шагов:

```env
MAX_STEPS=50   # По умолчанию
MAX_STEPS=100  # Для сложных задач
```

## 🎨 Chrome Extension (опционально)

### Установка:
1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. "Загрузить распакованное"
4. Выберите папку `extension/`

### Использование:
1. Кликните на иконку расширения
2. Введите задачу
3. Нажмите "Запустить"

**Примечание:** Расширение работает независимо от Python (пока).
Для полной интеграции нужен WebSocket сервер (TODO).

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема: Ошибка импорта

**Решение:**
```powershell
pip install -r requirements.txt --force-reinstall
```

### Проблема: Браузер не открывается

**Решение:**
```powershell
python -m playwright install chromium --force
```

### Проблема: API ключ не работает

**Решение:**
- Проверьте что в `.env` ключ начинается с `sk-ant-api03-`
- Проверьте что файл называется именно `.env` (без .txt)
- Перезапустите скрипт

### Все остальное:
📖 См. `docs/QUICK_START.md` раздел "Типичные проблемы"
